# ng-ecommerce — Backend

Backend del e-commerce de computadoras gamer, componentes y periféricos.

## Stack
- NestJS + TypeScript
- PostgreSQL (Neon)
- TypeORM

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run start:dev
```

## Build producción

```bash
npm run build
npm run start:prod
```
